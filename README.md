# Gene Expression Disease Classification

This project focuses on beginner-level bioinformatics and machine learning analysis using synthetic gene expression data.

The goal of the project is to analyze gene activity patterns and identify disease-associated genes using Python-based data analysis and machine learning techniques.

---

## Project Objectives

- Explore high-dimensional genomics data
- Compare healthy vs diseased patients
- Identify genes with strong disease-related signals
- Visualize gene expression differences
- Build a machine learning model for disease classification

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## Dataset Information

Synthetic Gene Expression Dataset for Disease Classification

Dataset contains:

- 2000 simulated patients
- 3000 gene expression features
- Binary disease labels
    - 0 = Healthy
    - 1 = Diseased

The dataset simulates realistic biomedical genomics data while remaining fully synthetic and privacy-safe.

---

## Dataset Source

The dataset used in this project was downloaded from Kaggle.
